Every task that used to fall on you — captured, connected, organised, and ready — without you lifting a finger.

| Feature | What it's for |
| --- | --- |
| [Voice & WhatsApp](/features/voice-and-whatsapp) | Capture on the go without opening the app |
| [Folder watching](/features/folder-watching) | Automatically file things that land in a folder, like Downloads |
| [Meeting notes](/features/meeting-notes) | Turn recordings into structured notes, decisions, and follow-ups |
| [Ask anything](/features/ask-anything) | Find anything you've ever captured, in plain language |
| [Relationships (People & Accounts)](/getting-started/relationships) | Keep everyone you work with, visiting cards, and client accounts in one place |
| [Accounts](/features/accounts) | Organisations you deal with — prospects, clients, commercial context |
| [Projects](/features/projects) | Group captures, files, and context under one piece of work |
| [Threads](/features/threads) | A persistent record of an ongoing situation, with its own conversation |
| [Automations](/features/automations) | Workflows you define, and rules Dori proposes from your corrections |
| [Handoffs](/features/handoffs) | Portable context bundles you can hand to any AI model |
| [Council](/features/council) | Advisor personas that review your work from a specific angle |
| [Create & share](/features/create-and-share) | Draft documents from what Dori already knows, instead of a blank page |
| [Connections](/features/connections) | Connecting your devices, and read-only sources like Gmail |
| [Audit trail](/features/audit) | Every read, write, call, and send Dori has made |

Looking for MCP — connecting external tools to Dori, or using Dori from Claude Code / Cursor? That's covered separately in [MCP](/mcp).

None of these are separate modes you switch between — they all read from and write to the same vault, so a voice note you send on WhatsApp can end up linked to a person, a project, and later cited when you draft a document.
