You already have an AI model you reach for first — Claude, ChatGPT, Gemini, or Codex. Dori doesn't compete with them. It gives them the one thing every chat model is missing: **memory that actually persists, and follows you wherever you go**, see [Choose your AI provider](/getting-started/choose-your-ai-provider).

<Callout type="note">
**Zero Extra Cost for Subscribers**: If you already subscribe to Claude Pro/Max (`claude`), ChatGPT Plus (`codex`), or Antigravity, Dori connects directly to your local CLI sessions. You pay **$0 extra in API fees** to use Dori.
</Callout>

## Why Dori + Your Existing AI is Different

|  | AI Alone (ChatGPT / Claude / Gemini) | AI + Dori |
| --- | --- | --- |
| **Coexistence** | Isolated vendor silos with resetting memory | The persistent memory layer under all your models |
| **Token Efficiency** | Dumps raw files into chat, wasting thousands of tokens | Local engine searches & parses on Mac (**0 API tokens**) |
| **Pricing** | Subscription per app, plus separate API keys | Use existing CLI subscriptions (**$0 extra API cost**) |
| **Data Ownership** | Vendor cloud databases, no real export | Plain Markdown files on your computer you own forever |
| **Capture Channels** | Web chat box drag-and-drop only | Voice notes, WhatsApp, folder watching, desktop files |

## Engineered for Low Token Consumption

Unlike cloud AI tools that re-upload your entire project history to the LLM on every message, Dori's local Mac background engine handles file indexing, change detection, speech-to-text transcription, and SQLite full-text search **locally at 0 API token cost**. 

Dori only sends small, targeted snippets to your AI provider when generating a final document or synthesis — keeping your API bills minimal and making CLI pass-through blazing fast.

## Who this is actually for

If your work is complex, your context is scattered across ten tools, and you're spending real time just *filing* — this is built for you specifically:

- **Founders** running a company inside their head — the investor call, the product decision made on a walk, the open thread with a co-founder — scattered across notes, WhatsApp, and memory until now.
- **Business leaders** walking into ten meetings a week who want to walk in *ready*, with everything said last time already in hand.
- **Consultants & advisors** holding a dozen clients' worth of context at once, each one needing to stay cleanly separate.
