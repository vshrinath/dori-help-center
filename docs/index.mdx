Dori is your local AI executive assistant. Share on WhatsApp, drop a voice note, or forward a file — Dori organizes it, remembers it, and has it ready the moment you need it.

Rather than competing with your existing AI subscriptions (Claude, ChatGPT, Gemini), Dori sits underneath them as a **permanent, local memory layer**. Your files, decisions, and meeting histories are stored on your Mac as plain Markdown you own.

- **Use Your Existing Subscriptions**: Connect your existing Claude Pro/Max (`claude`) or ChatGPT Plus (`codex`) CLI session to pay **$0 extra in API fees**.
- **Token Optimized**: File indexing, speech transcription, and local search run on your Mac at **0 API token cost**, sending only targeted snippets to your AI model.

<Callout type="note">
**The Dori Philosophy**: Read our founding principles on memory ownership, token consciousness, radical interface simplicity, and zero vendor lock-in — see [The Dori Philosophy](/philosophy).
</Callout>
