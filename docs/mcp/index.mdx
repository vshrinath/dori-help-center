[MCP](https://modelcontextprotocol.io) (Model Context Protocol) is the open standard Dori uses to talk to external tools — in both directions.

- **[Connect web research & workspace tools](/mcp/mcp-servers)** — pull live web search, articles, and external tools into Dori's memory.
- **[Use Dori in your coding IDE or chatbot](/mcp/use-dori-elsewhere)** — access your Dori vault memory straight from Claude Code, Cursor, or other AI clients.

Both live under **Settings → Connections** in the app; they're split out here because they answer two different questions (what external tools can Dori reach, vs. which AI tools can reach Dori's memory).
