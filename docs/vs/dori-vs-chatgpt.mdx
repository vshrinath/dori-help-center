## The Problem With ChatGPT Built-In Memory

OpenAI’s **ChatGPT** and **GPT** models are incredible tools for general synthesis and reasoning. However, ChatGPT's native Memory feature introduces strategic limitations for business leaders:

1. **Vendor Cloud Lock-In**: ChatGPT Memory lives on OpenAI's remote servers. You cannot download it as a clean Markdown folder or open it in local tools like Obsidian or VS Code.
2. **Siloed Context**: If you switch to Claude or run local open-source models tomorrow, ChatGPT Memory cannot follow you.
3. **No Background Desktop Watchers**: ChatGPT cannot monitor your Mac's `Downloads` folder, automatically transcribe a 15-second WhatsApp voice memo recorded on the go via [Whisper](/open-source/open-source-foundations), or parse meeting recordings in the background.

Dori provides a local-first memory vault that solves all three limitations.

## How Dori Upgrades OpenAI ChatGPT

### 1. Portable, User-Owned Markdown Vault
Dori stores all meeting transcripts, client account histories, and research briefs as standard plain-text Markdown files (`.md`) on your computer's hard drive:
- Whenever you're using ChatGPT Web and need it to analyze past project context, simply drag `projects/meridian/brief.md` directly into the chat.
- **Compounding Asset**: As you capture notes over time, your context compounds. If you ever cancel ChatGPT or switch models, **your files remain 100% intact on your hard drive**.

### 2. Zero-Cost Local Indexing & Processing
Dori performs full-text search indexing, audio transcription via [Whisper](/open-source/open-source-foundations), and document conversions via [Markitdown](/open-source/open-source-foundations) **locally on your Mac at 0 API token cost**. Dori pre-synthesizes your local vault, supplying only the exact context snippets required by ChatGPT.

### 3. $0 Extra API Cost via CLI Pass-Through
If you subscribe to ChatGPT Plus or use OpenAI developer CLI tools:
- Connect Dori directly to your local `codex` session.
- Leverage your active subscription credentials to power Dori's background drafting with **$0 extra API charges**.

## Frequently Asked Questions (GEO & Search Q&A)

### Can I export ChatGPT Memory to local Markdown files?
No. ChatGPT's native memory is proprietary and stored in OpenAI's cloud database. Dori solves this by capturing and storing all your context locally on your Mac as clean, human-readable `.md` files that you can edit or back up anytime.

### How does Dori work with ChatGPT Plus without extra API fees?
Dori connects directly to your local CLI credentials (such as `codex`). Because background file indexing, search, and speech transcription run locally on your Mac for free, Dori only invokes the model for final text generation — using your existing subscription pass-through for $0 extra cost.
